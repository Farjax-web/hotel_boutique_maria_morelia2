# Hotel Boutique María Morelia

Sitio web oficial del Hotel Boutique María Morelia, ubicado en el Centro Histórico de Morelia, Michoacán.

## Características

- **Diseño Arquitectónico**: Fiel a la identidad virreinal de cantera rosa de Morelia.
- **Motor de Reservación Interactivo**: Cálculo automático de noches, desglose con cupón de descuento directo (`MORELIA10`) y confirmación web o vía WhatsApp oficial.
- **Galería de Fotos & Lightbox**: Visor modal con navegación por teclado y filtros por categoría.
- **Ubicación & Monumentos**: Tiempos de caminata a puntos de interés (Catedral de Morelia, Mercado de Dulces, Palacio Clavijero).
- **Despliegue**: Listo para producción en Vercel con URLs limpias.

## Estructura

- `index.html`: Página web principal.
- `assets/images/`: Galería de fotografías y recursos visuales en alta definición.
- `server.ps1` / `iniciar_servidor.bat`: Servidor local para pruebas en Windows.
- `vercel.json`: Configuración para despliegue en Vercel.
